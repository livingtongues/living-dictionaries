## How the `gloss.*` set was translated

The code (`1PL`, `ERG`, `NMLZ`, …) is invariant — only the English *expansion* was translated, the
way linguistics literature in each language expands Leipzig codes.

- **Composed, not free-typed.** Each locale module declares person atoms, number atoms and a combo
  template, so the 15 person/number keys are generated mechanically and stay internally consistent:
  `es` "primera persona del singular", `de` "erste Person Singular", `ru` "первое лицо единственного
  числа", `zh-TW` 第一人稱單數, `ar` "متكلم مفرد", `vi` "ngôi thứ nhất số ít", `am` "አንደኛ መደብ ነጠላ",
  `ha` "mutum na farko, tilo". The other 96 codes were authored per locale.
- **Terminology anchored** on the existing `ps.*` part-of-speech catalog for each locale (queried
  from prod first), so `CLF`/`REFL`/`CAUS`/`DIM`/`REDUP`/`PTCP` etc. match the words that dictionary
  already uses — while deliberately NOT copying a few weak legacy `ps.*` AI rows (e.g. fr
  `tns`="marqueur de tension", `mod`="marqueur d'humeur"; the gloss rows use *temps* / *mode*).
- **Person naming for Indic locales avoids the 1st/3rd trap**: `bn`/`as` উত্তম / মধ্যম / নাম পুরুষ,
  `hi` उत्तम / मध्यम / अन्य पुरुष, `or` ଉତ୍ତମ / ମଧ୍ୟମ / ଅନ୍ୟ ପୁରୁଷ — named, not ordinal, so
  "প্রথম পুরুষ = 3rd person" can't be misread. A parenthetical (প্রথম ব্যক্তি) disambiguates.
- **Arabic** uses the traditional متكلم / مخاطب / غائب series with مفرد / مثنى / جمع.
- Where a language has no native term (Leipzig-specific categories in `sw`, `ha`, `am`, `or`), the
  value is a descriptive phrase plus the international term in parentheses, e.g. `ha` ANTIP
  "akasin fi'ili da aka aikata (antipassive)", `am` CVB "ንዑስ አንቀጽ ግስ (ኮንቨርብ)".
